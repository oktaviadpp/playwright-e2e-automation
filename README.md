# 🚀 playwright-e2e-automation

An end-to-end automation framework built with **Microsoft Playwright**, designed with clean architecture, modular components, and maintainable patterns.  
This project automates test scenarios for the following application:

🔗 **Test Website:** https://opensource-demo.orangehrmlive.com/

---

## 📌 Test Cases
All test cases used in this project are documented here:

🔗 **Test Case Document:** *https://bit.ly/test-scenario-orangehrm*

---

## ✨ Features
- ⚡ Fast & reliable end-to-end tests  
- 📦 Page Object Model (POM)  
- 🔍 UI + API + Visual testing  
- 🧩 Custom fixtures & utilities  
- 📊 HTML & Allure reporting  
- 🔄 GitHub Actions CI pipeline  
- 🗂️ Scalable & enterprise-ready folder structure  
- 🔒 Covers login flow, dashboard validation, and navigation using the OrangeHRM demo site

---

## 📁 For Running Playwright Test
```bash
npx playwright test tests/test.spec.js --headed --debug
```
